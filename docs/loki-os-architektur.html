Der Schlüssel-Workflow: In Nextcloud Dateien zusammenklicken → Public-URLs → an Lokyy OS senden → im Chat sofort referenzierbar. Binärdaten werden nie kopiert, nur per URL referenziert. Eine Markdown-Notiz im Brain verlinkt das Bild in Nextcloud → git bleibt leicht, die KI arbeitet trotzdem damit.
Prinzipien:  1) Datentyp trennen — Text→Forgejo, Binär→Nextcloud.  2) Referenzieren statt kopieren — Public-URLs verbinden die Welten.  3) Lokyy OS föderiert — speichert selbst nichts Schweres, orchestriert die MCPs.  4) Alles remote — von überall, jede KI.
